# **Software Developer Technical Assessment - Marketplace**

## **Objective**

Build a simple **marketplace storefront** where customers can browse products and an administrator can manage the products.

### **Required Stack**

- **Frontend:** React + Vite

- **Backend:** Node.js (Any Node.js Based framework is acceptable)

- **ORM:** Drizzle ORM or Prisma ORM

- **Database:** PostgreSQL running with Docker

- **UI:** Any UI library or custom CSS

- **Authentication:** Not required

### **Required Features**

#### **1. Storefront**

Create a homepage where products are showcased.

#### **2. Product Management**

Implement full **CRUD functionality for products** :

- Create products
- View products
- Edit products
- Delete products

A simple management interface should be provided for these operations.

### **Deliverables**

- Working marketplace homepage
- Product management interface
- Backend supporting product CRUD
- README with instructions for running the project

### **Extra Credit**

Additional points may be awarded for thoughtful implementation and a polished, user-friendly UI/UX, **including but not limited to** :

- Excellent visual design and consistency
- Responsive and mobile-friendly experience
- Effective search and filtering
- Well-organized product categories
- Clear loading, error, and empty states
- Robust and user-friendly form validation
- Smooth and intuitive user interactions

### **Important**

The implementation details are intentionally left open. The developer is expected to make appropriate decisions regarding the API design, database schema, project structure, validation approach, and other technical aspects.

The developer should be able to **explain and justify their technical decisions** and answer questions about the project and its implementation.
